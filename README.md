# GBD---Autoimmune-Thesis
R code for data extraction and statistical analysis of autoimmune diseases using GBD data
Τα δεδομένα προέρχονται από το GHDx/GBD και δεν περιλαμβάνονται στο παρόν δημόσιο αποθετήριο. Για την αναπαραγωγή της ανάλυσης, ο χρήστης πρέπει να κατεβάσει τα αντίστοιχα δεδομένα και στην συνέχεια να ορίσει την μεταβλητή BASE στην αρχή του Rmd.
